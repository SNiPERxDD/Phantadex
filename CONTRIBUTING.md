# Contributing

Contributions are welcome. Changes should remain focused, testable, and technically documented.

## Guidelines

1.  **Platform Safety**: Keep browser interaction changes narrow and reviewable.
2.  **No Bloat**: Keep documentation technical and precise.
3.  **Cross-Platform**: Ensure changes work on both macOS and Windows (or handle fallbacks gracefully).

## Issue Reporting

*   **Bugs:** Open an issue with the "Bug" label. Include reproduction steps and `pdex watch` logs.
*   **Features:** Open an issue with the "Enhancement" label. Describe the use case and expected behavior.

## Pull Requests

1.  Fork the repository.
2.  Create a feature branch (`git checkout -b feature/short-description`).
3.  Commit your changes (`git commit -m 'feat: describe change'`).
4.  Push to the branch.
5.  Open a Pull Request.
